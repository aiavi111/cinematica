# Орбита кинозалы

Демо-сайт кинотеатра: 3D-зал на three.js, выбор сеанса и мест прямо в зале, вид на экран с выбранного кресла.

Статический сайт без сборки: `index.html`, код зала в `js/`, афиши в `posters/`.
Запуск локально: `python3 -m http.server` в этой папке, затем открыть http://localhost:8000.
